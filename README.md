# Login React — Sinduscon

Projeto full-stack de autenticação com interface web e backend Node.js/Express. O backend usa validação de entradas, Sequelize e MySQL.

## Stack
- React (interface)
- Node.js e Express
- Sequelize e MySQL
- bcrypt e express-validator

## Como executar
O backend fica em `back-end`; instale as dependências com `npm install` nessa pasta. O `package.json` do backend não define script de inicialização, portanto execute o ponto de entrada `index.js` com Node após configurar o banco e as variáveis necessárias.
