# React Login — Sinduscon

A full-stack authentication project with a web interface and a Node.js/Express backend. The backend uses input validation, Sequelize, and MySQL.

## Stack
- React (interface)
- Node.js and Express
- Sequelize and MySQL
- bcrypt and express-validator

## Run
The backend is in `back-end`; install its dependencies with `npm install` in that folder. Its `package.json` does not define a start script, so run the `index.js` entry point with Node after configuring the database and required environment variables.
